## Cara Menjalankan Aplikasi

1. **Pastikan Python sudah terinstall** (cek dengan `python --version`).
2. **Buka terminal di folder proyek**, lalu (opsional) buat virtual environment:
   ```
   python -m venv venv-kelompok3
   venv-kelompok3\Scripts\activate
   ```
3. **Install library yang dibutuhkan:**
   ```
   pip install -r requirements.txt
   ```

4. **Jalankan dashboard:**
   ```
   python -m streamlit run app.py
   ```

5. Browser akan terbuka otomatis. Jika tidak, buka `http://localhost:8501`.
